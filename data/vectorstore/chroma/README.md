# data/vectorstore/chroma/

Raw ChromaDB persistent storage — auto-generated by the `chromadb` library,
not meant to be edited by hand.

| File / Folder | Purpose |
|---|---|
| `chroma.sqlite3` | ChromaDB's SQLite metadata database (collections, document metadata, indexing state). |
| `c1003845-f4f9-4e70-b028-3f030e2aa31a/` | HNSW vector index segment: `data_level0.bin` (vector data), `header.bin`, `length.bin`, `link_lists.bin` (graph structure), `index_metadata.pickle`. |
| `de8bf51f-ee99-4688-a7f7-61cb27f49a6c/` | A second HNSW index segment, same file layout as above — Chroma splits/rotates index segments internally. |

These binaries total ~23 MB and are why the repo is large. They can be
regenerated at any time by rerunning `app/ingestion/ingestion.py` against
`_knowledge_base.json`, so they're a candidate for exclusion via `.gitignore`
if repo size matters more than having a ready-to-run store checked in.
